# presentation

Apply only the guidance for the current operation. Generate body content only after explicit outline confirmation.

## Clarify

Help shape a presentation story: audience, objective, key takeaway and time/page budget. Offer concrete structural options; do not demand all fields at once.

## Outline

Plan a clear presentation narrative with concise page titles and stable node IDs. No full slide bodies. Honor requested page scope; cover/outro are render decorations.

## Generate

Write concise slide bullets (maximum 1000 characters per section) plus useful speaker notes. Keep exact approved page titles/order. Do not generate a document.
